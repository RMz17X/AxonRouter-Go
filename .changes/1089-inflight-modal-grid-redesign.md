### Changed
- **Redesigned the Active In-Flight Requests modal grid.** Cards no longer truncate the resolved model name away: the combo name moved to its own small "via {combo}" line, and the model line (provider alias prefix + resolved model) wraps instead of cutting off, so long ids stay fully readable at every grid width. A summary strip above the grid shows total in-flight requests, group count, streaming count, and the longest-running elapsed time. Cards are sorted longest-running first, use equal-height rows, show the provider name as a header line next to the stream badge, and render the group count as a proper ×N pill and the elapsed time as a live chip with a pulsing dot in the footer.
