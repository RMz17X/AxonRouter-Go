The smart router now judges tiers, not models — a deliberate divergence from upstream's System One design. Upstream had the decision model pick one member out of the combo and report a confidence for that pick; with near-duplicate members the certainty split across lookalikes and the configured threshold practically never opened (measured on the live `auto` combo: 75 of 75 decisions below threshold, confidence median 0.22 against a 0.5 floor). The combo's Easy/Hard pools are already the operator's classification, so the router is now asked the only open question — does this request belong to the easy tier or the hard tier — with each tier's criteria naming its pool members. The chosen tier's members lead in combo order and the other tier stays in the chain as fallback, so routing can never fail a request. Session stickiness still pins a concrete model (the chosen tier's lead) for cache warmth; Smart Switch re-evaluates the tier and switches only above the confidence floor; a combo whose members all sit in one tier skips evaluation entirely and records no decision. The recorded smartDecision is unchanged in shape: verdict is the tier, model is the tier's lead.
