kimi-web's catalog again lists the legacy models that remain callable on the upstream API, next to the current generation. The current generation is unchanged: kimi-latest, kimi-k3 (displayed "K3.1 Pro") and the kimi-web catch-all ride the default slot. Kimi Search is unaffected: it is a media service on POST /v1/search, not a chat model.
