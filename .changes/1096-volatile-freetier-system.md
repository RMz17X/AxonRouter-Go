### Fixed
- Volatile free-tier providers (dahl, apinex) now get a special system so the client stays fast (owner directive, 2026-11-10): a 30-second per-candidate silence window replaces the combo-wide window for them (dahl's network-wide stalls burned the full 300 s window per attempt — measured 341-354 s — before the chain moved on), and a provider-wide circuit breaker benches every entry of the provider in the combo for 3 minutes after one member stalls or burns its attempts on upstream errors, so following requests skip the sick provider entirely and re-admission is automatic and cheap. The bench plugs into the existing timeout-bench machinery (`withoutBenchedModels` still returns the full chain when everything is benched, so a combo can never bench itself into silence). The same change also fixes a bench hole for every provider: a stalled HEDGED candidate used to continue without benching (the hedge branch skipped the timeout-bench call the sequential path makes), so a stalling hedged provider was retried at full price by every request.
