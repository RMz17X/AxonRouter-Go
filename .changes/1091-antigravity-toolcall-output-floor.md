## Fixed
- Antigravity tool calls no longer vanish when the client's output cap is small: Gemini's dynamic thinking shares maxOutputTokens and was measured spending 200-380 thought tokens on one-line tool tasks, so a cap of a few hundred tokens ended MAX_TOKENS with zero content and the client never saw its tool call. `hardenAntigravityRequest` now floors maxOutputTokens at 1024 on tool-bearing requests; requests without tools keep the client's exact cap. Follow-up to fragment 1090's decoy-cloaking fix (acceptance probes: refusals and decoy leaks gone, small-cap empties remained).
