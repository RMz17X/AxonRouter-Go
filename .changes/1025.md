# 1025 — Playground fits the shell exactly: the chat thread is the only scroller

## Symptom
- After the 1024 redesign the page still scrolled: the console root
  was sized `100dvh - 1.5rem` (main's padding), but the dashboard
  shell renders a TopBar above <main>, so the view overshot the
  available height by the TopBar's height and <main> scrolled anyway.

## Fix
- PlaygroundView measures its real container instead of guessing
  viewport math: on mount it finds the closest <main>, locks its
  overflow (restored on unmount), and sizes the console to main's
  content box (clientHeight minus the 24px padding) under a
  ResizeObserver, so the fit stays exact across window resizes,
  sidebar changes and phone rotation. The chat thread — already the
  only internal overflow-y-auto — becomes the single scroller.
