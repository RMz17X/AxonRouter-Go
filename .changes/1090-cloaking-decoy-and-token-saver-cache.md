### Fixed

- **Antigravity decoy tools no longer derail client tool use.** The 21 injected decoy tools were described as "This tool is currently unavailable.", which taught the model to refuse tasks in plain text ("the `run_command` tool is currently unavailable") instead of calling the client's own tools, and a model that called a decoy anyway had that call forwarded to the client as a call to a tool it never declared (both reproduced live through combo models on 2026-11-10). Decoys now carry functional descriptions matching the real IDE tools — a deliberate divergence from upstream decolua/9router, recorded here; the fingerprint surface (decoy names, schemas, count) is unchanged. On the response side, the chat Gemini handler now hands the translators the request's live decoy set (decoys the client did not declare itself): calls to them are dropped from non-streaming and streaming responses, and a non-streaming response left with nothing else fails the attempt with `ErrDecoyOnlyResponse` so the fallback chain retries another account or member instead of handing the client an empty completion.
- **Claude OAuth decloaking keeps calls to the client's own tools.** The decloaker converted any call to a decoy name into a "[Tool X is unavailable]" text block — including when the client had declared that exact tool (renamed to `X_ide` by the cloak), so a model using the client's tool under its natural name lost the call. A decoy-named call is now kept as a tool call when the cloak map shows the client declared that name.
- **Token savers run once per request instead of once per connection attempt.** `applyTokenSavers` sat inside the per-attempt forward path, so during a provider 429 storm every retry (and every hedged parallel attempt) re-ran the full RTK filter pipeline, injection scan and prompt injections over the identical ~500 KB client body — the burn behind the app container's 150–320% CPU spikes. Results are now cached per request, keyed by body hash and body format, and reused by every attempt including hedged and combo paths.
